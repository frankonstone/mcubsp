# STM32H753 description review

This is the source review record for `PLN-0014`, completed 13 September 2026.
The selected concrete identity is `STM32H753VI` in `LQFP100`; the description
also retains the eight package variants and six device/package suffixes in the
declared xI baseline. It is declarative metadata only. Startup, ISR dispatch,
MMIO execution, peripheral sequencing, board aliases and RTOS integration are
deferred to later plans.

The modeled silicon revision IDs are Y/W `0x1003`, X `0x2001`, and V
`0x2003`. The description keeps the 400 MHz limit for the older revision
groups and the 480 MHz V-revision limit. It does not model the nonexistent FPU
interrupt on NVIC line 81.

Register catalogues record the access width, writable mask, known-reset mask,
reserved-bit policy and provenance. A zero known-reset mask means unknown or
not reviewed, never an assumed reset value. Peripheral event identities are
separate from fixed NVIC line numbers, and DMAMUX request numbers are separate
from both.

## Native differences preserved

- TIM1/TIM8 expose complementary outputs, center-aligned operation and dead
  time; TIM2/TIM5 use 32-bit counters without those advanced-output features.
- DMA1/2 cannot reach ITCM or DTCM. BDMA is limited to D3 SRAM4 and backup
  SRAM. MDMA has an explicit engine kind and reaches the TCM regions.
- AXI, D2 and D3 SRAM regions carry `software_maintained` cache policy; their
  detailed metadata says DMA users require cache maintenance.
- Pin legality depends on the selected package and an exact alternate-function
  route. `PK0`, for example, is unavailable in LQFP100 but present in LQFP208
  and TFBGA240+25.

## Correction overlay and remaining gap

`GAP-STM32H753-001` is `correction-overlay-applied` for the complete inventory.
The ADC kernel maximum is 80 MHz for VOS0/VOS1 and 40 MHz for VOS2/VOS3, and
GPIO AFRH is represented at offset `0x24`. The live correction list also says
that entries in RM0433 Table 3 must be removed. Consequently, DMA reachability
uses the reference manual's per-engine narrative rather than the defective
matrix. The complete bus-interconnect unit is now accounted using the
correction overlay and per-engine narrative. Removed Table 3 routes are not
exposed, and no unsupported reachability is inferred from the defective table.

`PLN-0013` records the DS identity/package unit and RM0433 chapters 2–61 in the
public `complete_source_inventory`. The initial typed register catalogues remain
the driver-facing slice; deferred driver support is not incomplete description
coverage.

## Verification boundary

Host tests instantiate the shared description contract, check the source and
inventory records, validate register side effects, pin/package rules, clock
limits, fixed interrupt routing, DMA reachability/cache policy, and capability
differences. Negative compile cases reject an LQFP100-unavailable pin and an
advanced-timer feature requested from TIM2's capability set. The public header
is also included by the Cortex-M7 metadata compile probe.

These checks establish description consistency. They are not evidence of boot,
live MMIO, transfer completion, board execution, or working drivers.
