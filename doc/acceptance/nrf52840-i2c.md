# nRF52840 I2C software verification

Recorded 27 October 2026 for REQ-0054 / PLN-0041. This increment adds CPU-driven
TWI0/TWI1 controllers and the Pro Micro TMP102 application. Physical I2C and
sensor acceptance remain outstanding.

## Scope and baseline

- Nordic nrfx v3.2.0 `mdk/nrf52840.h` and `nrf52840_bitfields.h` supply the TWI
  register/field baseline. The same tag's `drivers/src/nrfx_twi.c` was reviewed
  for byte-boundary suspend/STOP and combined-transfer sequencing. No vendor
  driver code is linked or required.
- Both native instances and configurable valid GPIO routes are represented.
  TWI0 defaults to Zephyr's SDA P1.00 / SCL P0.11 route. Shared serial-instance
  ownership is independent of pin binding; ENABLE prevents taking over an
  already-enabled native block.
- Finite seven-bit write, read and repeated-START combined operations use the
  existing fixed operation pool, device leases, deadlines and cancellation.
  Rate solving reports nominal hardware encodings for 100/250/400 kHz and
  validates rise/fall assumptions. No automatic bus-line recovery, multi-controller
  arbitration or EasyDMA behavior is claimed.
- Success requires expected byte counts and STOPPED. RX uses BB_SUSPEND and
  prearmed final-byte BB_STOP. The simulation exercises STOPPED/RXDREADY
  arriving immediately after RESUME, so a pending final byte is consumed on
  the next bounded poll rather than mistaken for premature STOP.
- Cancellation waits at most 1024 STOPPED reads, then disables/checks the
  peripheral and clears stale events. Failed cleanup or MMIO errors fault the
  backend; hardware ownership is released only by successful shutdown. A fresh
  backend/runtime is required afterward, preserving retired-slot semantics.

## Executed checks

Host: macOS arm64, AppleClang 21.0.0.21000334. Cross compiler: Arm GNU 15.2.1.

| Check | Result |
| --- | --- |
| Full native verification | 52/52 CTest entries; 319 merged cases, zero failures |
| Focused I2C cases | 15 cases linked to REQ-0054 |
| GPIO regression | All seven existing Nordic GPIO/facade cases pass |
| Negative compile cases | Reserved/duplicate pins and invalid instance rejected with expected diagnostics |
| Host public headers | 118 isolated translation units compile |
| Cortex-M4 public headers/contracts | 118 isolated headers and architecture contracts compile; barrier instruction check passes |
| Repository examples | Blink and TMP102 link and emit bounded UF2 output |
| Source application | Standalone `example/tmp102` builds through the public helper |
| Relocated installed application | Installed starter copied outside the checkout; package moved to a path with spaces; TMP102 links and emits UF2 |
| Installed runner planning | Explicit temporary UF2 mount validates TMP102 ELF/input records and payload; no upload is written by dry run |
| Focused trace validation | REQ-0054 has no validation diagnostics after native evidence regeneration |

The focused cases cover native presets and electrical assumptions, open-drain
setup/cleanup, ownership across bindings, enabled external-block rejection,
finite TX counts, repeated START without STOP, final-byte races, premature STOP,
observable NACK/error classification, stuck lines, invalid and busy requests,
unconsumed slot capacity, timeout/cancel, stale events, initialization/data MMIO
failures, failed-disable ownership retention, simultaneous TWI0/TWI1 composition,
shared address/pin leases, and the actual TMP102 protocol driver over the facade.

For one repository TMP102 build, `arm-none-eabi-size` reports text 9460, data 4
and BSS 172 bytes. ELF flash load starts at `0x26000`; initialized RAM uses VMA
`0x20000000` and flash LMA `0x284F4`; the Thumb entry is `0x2807D`. These section
sizes exclude the factory bootloader/SoftDevice, reserved stack and peak stack.

Reproduce:

```sh
cmake --preset macos-arm64
cmake --build --preset macos-arm64
cmake --preset promicro-nrf52840
cmake --build --preset promicro-nrf52840 --target examples
```

The CI workflow now includes the Pro Micro TMP102 link target; hosted CI was not
run in this local session. Native coverage artifacts were not regenerated.

## Remaining physical scope

No new image was uploaded during this increment. The earlier user-observed
[Blink result](promicro-nrf52840.md) remains scoped to its recorded image and
does not establish I2C behavior. Connect a known 3.3 V sensor and external pull-ups
to the documented pins, record actual board/silicon and firmware identities,
observe sensor reads, and capture repeated START, final NACK/STOP, actual rates
and error/cleanup behavior before adding physical claims. The full nRF52840
description/errata audit and remaining peripheral backends remain separate work.
