# TI TMP102

Catalog identity: `device:ti/tmp102@datasheet-sbos397i`.

Wire SDA/SCL to the selected board profile, share ground, use compatible supply and I2C pull-ups, and select the address implied by ADD0 (default 0x48). The application must wait for a completed conversion. See the complete TMP102 application generated by the frontend.

## Implementation and focused checks

Public implementation: `include/mcuhw/device/sensor/tmp102.hpp`. Required transports: i2c.

Focused test sources:

- `tests/device/test_tmp102.cpp`
- `tests/io/test_io_i2c_devices.cpp`

See [catalog contribution and validation](../../../doc/development/catalog.md) for checks.

## Limits

Reads existing conversions through a claimed I2C endpoint; does not wake a shutdown sensor or trigger a fresh conversion.

Physical TMP102 board/device acceptance is missing; bus compatibility does not imply a tested composition.
